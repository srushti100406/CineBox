# CineBox

CineBox is a modern movie discovery web application that allows users to explore movies through a clean, interactive, and responsive interface.

## Overview

CineBox is built with React and TypeScript, with Convex used for backend services, database management, and authentication. The application focuses on providing a smooth and engaging movie browsing experience with a modern UI, responsive design, and interactive animations.

## Features

- Browse and explore movies
- Search and discover movies
- View movie details
- User authentication
- Responsive design for desktop and mobile
- Modern and interactive user interface
- Smooth animations
- Backend and database integration with Convex

## Tech Stack

- **Frontend:** React 19, TypeScript, Vite
- **Routing:** React Router v7
- **Styling:** Tailwind CSS v4, Shadcn UI
- **Icons:** Lucide Icons
- **Backend & Database:** Convex
- **Authentication:** Convex Auth
- **Animations:** Framer Motion
- **3D Graphics:** Three.js
- **Package Manager:** Bun

##Installation

Make sure Node.js and npm are installed on your system.

git clone <repository-url>
cd CineBox
npm install
npm run dev

Open the local URL shown in the terminal (usually http://localhost:5173) in your browser.
